# 日本語の文体

日本語の本文、見出し、リスト、指示を書くときに適用する。

## 常体

常体を用いる。ですます調、敬語、婉曲表現の「〜と思われます」「〜と考えられる」「〜していただく」を用いない。常体は「だ」「である」の反復を意味しない。文の役割に応じて、動詞による終止、体言止め、「〜のこと」「〜すること」を使い分ける。

- 体言止め: 見出し、リスト項目、表のセル、要点の提示で、述語を補わなくても関係や意味が確定する場合に用いる。連続する本文を体言止めだけで構成して主体や関係を曖昧にしない
- 指示の終止形: 読者へ短い行為を求める文は「参照のこと」「確認のこと」「実施のこと」などの「動作名詞＋のこと」を既定とする。目的語、条件、方法を伴って不自然になる場合は「〜すること」を用いる。事実や通常の手順には「〜する」を用いる
- 規範の強度: 義務と推奨を区別する場合は、義務を「必ず〜のこと」、推奨を「〜を推奨する」など、強度を判別できる形にする
- コピュラ: 「X は Y である」は、定義、同定、分類、判断に用いる。動作、配置、責務、条件を「〜である」で終えない

## 動詞と主体

- 意味上の主体: 選択、決定、記録、実行、保証を実際に担う人、役割、ソフトウェア、機器、仕様を特定する。意味上の主体の特定と、文法上の主語の明示を分けて判断する
- 主語の明示: 見出し、導入文、直前の文から主体が一意に定まる場合は主語を省略してよい。主体が変わる箇所、責務の境界、複数の解釈が生じる箇所だけで明示する。同じ主体名を各文へ機械的に反復しない
- 設計判断: 人または役割が設計値、規則、採用対象を「選ぶ」「定める」「決める」。成果物を擬人化して判断の主体にしない。Profile などの成果物は、決定した値や事実を「記録する」先として書く
- 実行時の動作: 実際に処理するソフトウェアまたは機器を主体にしてよい。システム処理で結果が定まる場合は「選ばれる」「決まる」「実行される」と書き、行為者の識別が必要な受動文では行為者も明示する
- 静的保証: 仕様、インターフェース、型、プロトコルが制約や性質を保証する場合は、それらを主体にしてよい
- 関係を表す動詞: 規則には「定める」、配置には「置く」「収める」、記録先には「記録する」、責務には「担う」、内部構造には「含む」「ある」を用いる。「持つ」「扱う」だけで異なる関係を括らない

## 表記

- 同じ概念には同じ用語を用いる。略称や別名が必要な場合は、初出時に正式名との対応を定義する
- リスト項目冒頭のラベルは、太字にせず `用語: 説明` の形式を用いる
- 見出し、ラベル、参照では「これ」「それ」「上記」「下記」だけで対象を示さず、対象名を記す
- 句読点、英数字、用語の表記は、対象リポジトリの既存規則へ揃える
