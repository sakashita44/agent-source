# Web サイト・Web アプリの開発

Web サイトや Web アプリを開発する際の判断対象と確認先をまとめる。参考情報は調査の出発点であり、提案に先立って確認先で現行のガイダンスを確認する。

## デザインシステム

判断対象: 色、タイポグラフィ、余白、コンポーネント、アクセシビリティの基準として適用するデザインシステム

確認先: [デジタル庁デザインシステム](https://design.digital.go.jp/)

参考: 2026-09 時点では β 版の v2.18.0 が公開されており、官民を問わず利用できる。コンポーネントのコード例は HTML 版と React 版が提供されている。採用するフレームワークやコンポーネントライブラリが別のデザインシステムを前提とする場合は、併用する範囲を判断対象に含める。UI 文言の確認先は `writing-principles` の `references/ui-text.md` に定める。
