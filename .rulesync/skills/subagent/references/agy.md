# agyの利用方法

`agy`は、非対話実行によって独立した作業を委譲するために用いる。利用できるコマンド、モデル、オプションは、実行環境の`agy --help`と`agy models`で確認する。

## 非対話実行

`agy -p`に、目的、対象、許可範囲、制約、完了条件、必要な報告を含む自己完結したプロンプトを渡す。

- モデルは、ユーザーの指示があればそれに従う。指示がなければ、`agy models`が表示する候補のうち最も新しい世代のものを選ぶ
- 同じ世代に複数のティアがある場合は、上位のティアを選ぶ
- 推論強度は最上位を用いる。強度がモデルIDへ含まれる場合は、最上位の強度を持つIDを選ぶ
- `--print-timeout`には`10m`、`1h`のような単位付きの時間を指定する。既定時間は広いリポジトリ調査やMCPを使う調査には不足する場合があるため、[SKILL.md](../SKILL.md)のタイムアウト基準に従って値を決める
- ワークスペース外の対象が必要な場合は、追加ディレクトリを明示する
- `--dangerously-skip-permissions`を既定で付ける。全ツールの権限確認を省くため、アクセスしてよい対象と許してよい操作をプロンプトで限定してから実行する

### PowerShell例

プロンプトを変数へ読み込み、空でないことを確認して引数として渡す。

```powershell
$prompt = Get-Content '<prompt-file>' -Raw
if ([string]::IsNullOrWhiteSpace($prompt)) { throw 'prompt is empty' }
agy -p $prompt --model '<選んだモデルID>' --effort high --print-timeout 20m --dangerously-skip-permissions
```

`--output-format json`または`stream-json`は、結果を機械処理する場合や進捗イベントを取得する場合に用いる。構造を保証する必要がある場合は`--json-schema`を併用する。

## 権限と出力

headless実行は権限確認へ応答できない。必要な権限が許可されていない場合、ツール呼び出しが拒否されても標準出力が空のまま終了することがある。

`--dangerously-skip-permissions`を既定で付ける。権限確認の待ちを避け、調査でも編集でも同じ起動方法を使える。副作用の範囲は、アクセスしてよい対象と許してよい操作をプロンプトで明示して限定する。読み取りだけを求める委譲では、ファイルの作成、編集、削除とGit操作を行わないことをプロンプトへ書く。

呼び出し側の環境がこのオプションを拒否する場合は、設定ファイルの書き換えなどで迂回せず、拒否された事実と必要な理由を示してユーザーへ許可を求める。

テキスト出力は完了まで表示されない場合がある。実行中に出力が空であることだけで失敗と判断しない。終了後に出力が空、極端に短い、または調査記録を欠く場合は、標準エラー、ログ、権限拒否、タイムアウトを確認する。

## 入れ子

agyの内部では、サブエージェントからの再委譲を禁じない。入れ子の深さを1へ絞る設定も行わない。委譲した作業の分解はagy側の判断に任せる。

入れ子が深くなると並列度と消費が増える。想定より時間または出力量が大きい場合は、依頼の範囲を分割して個別に委譲する。
