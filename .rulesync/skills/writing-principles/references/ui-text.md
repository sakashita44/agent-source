# UI 文言の確認先

ボタン、ラベル、要否表示、エラーメッセージ、ダイアログ、リンクなどの UI 文言を書くときに確認するガイドラインを、対象のプラットフォームと言語ごとに定める。ガイドラインの規則は改訂されるため、文言を書く前に確認先で現行の内容を確認すること。

対象プロジェクトにスタイルガイドや既存 UI の表記規則がある場合は、それを優先する。どの確認先に従う場合も、同一インターフェース内では表記とトーンを揃える。

## プラットフォーム別の確認先

| 対象 | 確認先 |
| --- | --- |
| 日本語の Web サイト・Web アプリ | [デジタル庁デザインシステム](https://design.digital.go.jp/) |
| Android アプリ | [Material Design の Content design](https://m3.material.io/foundations/content-design/overview) |
| Windows アプリ | [Windows apps の Writing style](https://learn.microsoft.com/en-us/windows/apps/design/style/writing-style) |

表にないプラットフォームや言語の組み合わせでは、対象プラットフォームの公式ガイドラインを調査して確認先を特定する。

ネイティブアプリの日本語の文言では、デジタル庁デザインシステムは参考にとどめる。「※必須」などの Web フォームの表記は持ち込まず、対象プラットフォームのガイドラインに従う。
