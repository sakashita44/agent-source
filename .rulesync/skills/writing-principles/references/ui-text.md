# UI 文言の確認先

ボタン、ラベル、要否表示、エラーメッセージ、ダイアログ、リンクなどの UI 文言を書くときに確認するガイドラインを、対象のプラットフォームと言語ごとに定める。ガイドラインの規則は改訂されるため、文言を書く前に確認先で現行の内容を確認すること。

対象プロジェクトにスタイルガイドや既存 UI の表記規則がある場合は、それを優先する。どの確認先に従う場合も、同一インターフェース内では表記とトーンを揃える。

## プラットフォーム別の確認先

| 対象 | 確認先 |
| --- | --- |
| 日本語の Web サイト・Web アプリ | [デジタル庁デザインシステム](https://design.digital.go.jp/) |
| Android アプリ | [Material Design の Content design](https://m3.material.io/foundations/content-design/overview) |
| Windows アプリ | [Windows apps の Writing style](https://learn.microsoft.com/en-us/windows/apps/design/style/writing-style) |

表にないプラットフォームや言語の組み合わせでは、対象プラットフォームの公式ガイドラインを調査して確認先を特定する。

## デジタル庁デザインシステムの参照方法

デジタル庁デザインシステムには、UI 文言のみをまとめたページがない。文言の規則は各コンポーネントの「使い方」に記載されているため、対象とする UI 要素に対応するコンポーネントの使い方を確認する。例えば入力欄の要否表示やエラーテキストは、[インプットテキストの使い方](https://design.digital.go.jp/dads/components/input-text/usage/)に定められている。リンクの文言は、基本デザインの[リンクテキスト](https://design.digital.go.jp/dads/foundations/link-text/)を確認する。複数のコンポーネントにまたがって確認する場合は、[リソース](https://design.digital.go.jp/dads/resources/)で配布されている Markdown 版のドキュメントを用いる。

## Web 固有の表記

デジタル庁デザインシステムが定める表記のうち、要否表示の「※必須」「※任意」や、エラーテキスト冒頭の「＊」は、日本語の Web フォームの慣習である。これらの表記は Web サイト・Web アプリに限って用い、Android や Windows のネイティブアプリでは、対象プラットフォームのガイドラインに従う。

ネイティブアプリの日本語の文言でも、表記に依存しない原則はデジタル庁デザインシステムを参考にしてよい。例えば、エラーメッセージでは誤りの内容と訂正方法を示し、入力条件をプレースホルダーのみで示さない。
