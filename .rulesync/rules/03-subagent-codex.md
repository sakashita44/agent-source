## Codex から agy へ委譲する場合

Windows でコマンド名 `agy` の解決に失敗しても、それだけで `agy` を未導入と判断しない。Codex の sandbox は `PATH` 上のディレクトリの列挙を制限し、コマンド名による解決だけを失敗させる場合がある。名前解決に失敗した場合は、プロセスの `PATH` に含まれる各ディレクトリに `agy.exe` を連結した候補パスを `PATH` の順に組み立て、ファイルの存在を確認できた最初の候補を絶対パスで起動する。候補の確認にはディレクトリの列挙を用いず、組み立てたパスごとに存在を確認する。どの候補も確認できない場合に限り、ユーザーへ `agy.exe` の絶対パスを確認する。名前解決のために sandbox の権限追加や環境設定の変更を行わない。

Codex の sandbox または権限分類器が `agy.exe` の起動に承認を要求した場合は、Codex の承認手順に従う。拒否の診断と再試行は `subagent` Skill の「agy の利用方法」に従う。ユーザーの承認を得る前に、組み込みのサブエージェントなど別の委譲先へ切り替えない。
