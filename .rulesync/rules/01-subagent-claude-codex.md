## 委譲先の選択

通常の調査（web、コードベース）、情報抽出、比較、整理に加え、経緯を持たない立場での判定や方向性が決まった編集には、`agy` を基本の委譲先とする。

重要な設計相談、実装提案、アーキテクチャ評価では、委譲元とは異なる Claude Code または Codex と `agy` へそれぞれ相談し、独立した意見を得る。

これらの委譲先は CLI で起動する。Claude Code の組み込みのサブエージェントは、ユーザーが指定した場合と、`subagent` の fallback の手順でユーザーが承認した場合に限って用いる。
